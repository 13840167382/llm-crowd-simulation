# 人群流动决策逻辑

> `LocalCrowdDecisionEngine` — 本地人群决策引擎，在无法调用 LLM 或作为 LLM fallback 时使用。

---

## 1. 概述

`LocalCrowdDecisionEngine.TrySelectBestExit()` 是一个静态方法，基于**加权评分模型**为每个 agent 从候选出口中选择最优的下一目标区域。

每个候选出口都会计算 5 个维度的**子评分**，按配置权重加权求和，得分最高者即为选中出口。

---

## 2. 加权评分公式

```
totalScore = algorithmWeight × algorithmScore
           + crowdWeight   × crowdScore
           + distanceWeight × distanceScore
           + exitCapacityWeight × exitCapacityScore
           + attractionWeight   × attractionScore

finalScore = totalScore / weightSum
confidence  = Clamp01(finalScore)
```

若所有权重之和 ≤ 0，则退化为纯算法评分（`algorithmWeight = 1`，其余为 0）。

---

## 3. 五个评分维度

### 3.1 算法评分（Algorithm Score）

直接使用出口 DTO 的 `algorithm_score` 字段，由 `EnrichExitOptionsWithMapScores` 预先计算：

$$score = 0.7 \times attractionScore + 0.3 \times capacityScore$$

其中：
- `attractionScore`：该人群类型对目标区域类型的吸引力（经 contrast 放大）
- `capacityScore`：目标区域容量 / (容量 + 默认容量)

> 该评分仅基于**静态地图配置**，不依赖运行时人群分布。

### 3.2 拥挤度评分（Crowd Score）

$$crowdScore = 1 - \frac{targetLoad + predictedInflow + 1}{capacity}$$

| 变量 | 来源 | 说明 |
|------|------|------|
| `targetLoad` | `currentZonePopulation` | 目标区域当前人数 |
| `predictedInflow` | `predictedTargetInflow` | 本批次中已决定前往该区域的 agent 数 |
| `capacity` | `zoneCapacityById` | 目标区域容量（默认 120） |

- 值越接近 0，目标区域越拥挤
- `+1` 包含当前 agent 自身，避免 0 人区域推荐过度
- 随批次推进，`currentZonePopulation` 会递减（agent 离开），`predictedTargetInflow` 会递增（agent 前往）

### 3.3 距离评分（Distance Score）

$$distanceScore = \frac{1}{1 + distance / normalization}$$

| 变量 | 说明 |
|------|------|
| `distance` | NavMesh 路径距离（不可达时回退直线距离） |
| `normalization` | 归一化距离（默认 15m） |

- 距离越近，评分越接近 1
- 距离为 0 时，评分为 1
- 距离等于 `normalization` 时，评分为 0.5

### 3.4 出口通行能力评分（Exit Capacity Score）

$$score = \frac{passCapacityPerSec}{passCapacityPerSec + normalization}$$

| 变量 | 说明 |
|------|------|
| `passCapacityPerSec` | 出口每秒通行人数（来自拓扑配置） |
| `normalization` | 归一化值（默认 4） |

- 通行能力越大的出口得分越高
- 无出口数据时返回 0.5

### 3.5 人群吸引力评分（Attraction Score）

$$score = ApplyContrast(weight, contrast)$$

$$ApplyContrast(x, c) = Clamp01(0.5 + (x - 0.5) \times c)$$

| 变量 | 说明 |
|------|------|
| `weight` | 该人群类型对目标区域类型的吸引力权重（0~1） |
| `contrast` | 对比度放大系数（默认 2.0） |

**区域类型 ↔ 权重映射：**

| 区域类型 | 权重字段 | 默认值 |
|----------|----------|--------|
| `exhibit`（展览区） | `exhibit` | 0.4 |
| `commercial`（商业区） | `commercial` | 0.4 |
| `rest`（休息区） | `rest` | 0.2 |
| `service`（服务区） | `service` | 0.2 |
| `plaza`（广场） | `plaza` | 0.4 |
| `passage`（通道） | `passage` | 0.5 |
| `exit_final`（出口） | `exit_final` | 0.1 |
| 其他 | — | 0.5 |

**Contrast 效果示例（默认 2.0）：**

| 原始权重 | 放大后 |
|----------|--------|
| 0.9（很强） | 1.0 |
| 0.6（中等偏上） | 0.7 |
| 0.5（中性） | 0.5 |
| 0.3（较弱） | 0.1 |
| 0.1（极弱） | 0.0 |

---

## 4. 默认权重配置

```csharp
algorithmScoreWeight      = 0.30   // 算法评分权重
crowdPressureWeight        = 0.45   // 拥挤度权重（最高优先级）
distanceWeight             = 0.20   // 距离权重
exitCapacityWeight         = 0.05   // 出口通行能力权重
crowdTypeAttractionWeight  = 1.10   // 人群吸引力权重（高，因为 contrast 会压缩）
crowdTypeAttractionContrast = 2.00  // 吸引力对比度
defaultZoneCapacity        = 120    // 默认区域容量
distanceNormalizationMeters = 15    // 距离归一化（米）
exitCapacityNormalization  = 4      // 出口通行能力归一化
```

---

## 5. 出口过滤规则

以下出口会被**跳过**，不参与评分：

1. `exit_id` 或 `target_zone_id` 为空
2. `target_zone_id` 等于 `current_zone_id`（不走回头路）

---

## 6. 同分决胜规则

当两个出口加权总分相等时，按以下优先级决胜：

1. **吸引力评分** 更高者优先
2. 吸引力相同 → **算法评分** 更高者优先
3. 算法相同 → **exit_id 字母序** 更小者优先

---

## 7. 回退机制

如果 `TrySelectBestExit` 无法选出任何有效出口（所有候选均被过滤），调用方：

1. 调用 `TryResolveFallbackExit`：优先使用 `algorithm_recommendation` 对应的出口，否则取 `algorithm_score` 最高的出口
2. confidence 设为 0.05
3. reasoning 为 `"client_simulation: fallback_to_best_available_exit"`

---

## 8. 调用链路

```
DecisionBatchScheduler.BuildClientSimulationDecisions()
  → BuildCurrentZonePopulationMap()          // 构建当前区域人口快照
  → LocalCrowdDecisionEngine.TrySelectBestExit()  // 为每个 agent 评分选出口
    → CalculateCrowdScore()                  // 拥挤度
    → CalculateDistanceScore()               // 距离（NavMesh）
    → CalculateExitCapacityScore()           // 通行能力
    → CalculateAttractionScore()             // 人群吸引力
  → TryResolveFallbackExit()                 // 所有出口无效时的兜底
```

---

## 9. 地图信息 → 自然语言转化（LLM Prompt 构建）

`DecisionAgentPoint.TryBuildDecisionRequest()` 将每个 agent 的拓扑状态编码为结构化 JSON，其中 `dilemma_summary` 和 `nl_description` 是发送给 LLM 的自然语言字段。

### 9.1 数据结构

```json
{
  "agent_id": "uagent#12345",
  "crowd_type": "tourist",
  "current_zone_id": "main_hall",
  "stay_duration_ms": 16200,
  "patience_ratio": 0.81,
  "dilemma_summary": "观光游客已在主大厅停留16.2秒(耐心消耗较高，比较急迫(81%)), 偏好展览区, 当前面临出口选择困境。",
  "algorithm_recommendation": "exit_exhibit_a",
  "available_exits": [
    {
      "exit_id": "exit_exhibit_a",
      "target_zone_id": "exhibit_zone_01",
      "algorithm_score": 0.72,
      "nl_description": "通往exit_exhibit_a(展览区). 展览区对该类人群吸引力很强(权重0.9)."
    },
    {
      "exit_id": "exit_rest_01",
      "target_zone_id": "rest_zone_01",
      "algorithm_score": 0.31,
      "nl_description": "通往exit_rest_01(休息区). 休息区对该类人群吸引力较弱(权重0.2)."
    }
  ]
}
```

### 9.2 dilemma_summary 生成

由 `DecisionAgentPoint.BuildDilemmaSummary()` 构建，模板为：

```
{角色名}已在{区域名}停留{时间}(耐心消耗{标签}({百分比})), 偏好{区域类型}, 当前面临出口选择困境。
```

| 占位符 | 来源 | 转化逻辑 |
|--------|------|----------|
| `{角色名}` | `crowdType` | 通过 `ResolveCrowdTypeDisplayName` 查 `ExperimentManager` 运行时模板 → `display_name`（如 `tourist` → `观光游客`） |
| `{区域名}` | `currentZoneId` | 通过 `TopologySceneConfig.TryGetZoneById` → `zone_name`（如 `main_hall` → `主大厅`） |
| `{时间}` | `stayDurationMs` | 毫秒 → 秒，保留1位小数（`16200ms` → `16.2秒`） |
| `{标签}` | `patienceRatio` | `ResolvePatienceRatioLabel`：`<0.5`→`较低，不太着急`，`0.5-0.8`→`中等，开始有些焦虑`，`0.8-1.0`→`较高，比较急迫`，`>1.0`→`已超出容忍限度，非常急迫` |
| `{百分比}` | `patienceRatio` | `patienceRatio × 100` 取整 |
| `{区域类型}` | `algorithmRecommendation` | 从推荐出口的 `target_zone_id` 反查 `TopologySceneConfig.TryGetZoneById` → `zone_type` → `ResolveZoneTypeDisplayName`（如 `exhibit` → `展览区`） |

### 9.3 nl_description 生成

每个出口的 `nl_description` 由 `LocalCrowdDecisionEngine.BuildExitNaturalLanguageDescription()` 构建，模板为：

```
通往{出口名}({目标区域类型}). {目标区域类型}对该类人群吸引力{强度标签}(权重{权重值}).
```

| 占位符 | 来源 | 转化逻辑 |
|--------|------|----------|
| `{出口名}` | `exit_id` | 直接使用出口 ID 字符串 |
| `{目标区域类型}` | `target_zone_id` | 通过 `zoneTypeById` 字典 → `ResolveZoneTypeDisplayName` 转化为中文（`exhibit`→`展览区`，`commercial`→`商业区` 等） |
| `{强度标签}` | 人群吸引力权重 | `ResolveAttractionStrengthLabel`：`>0.7`→`很强`，`>0.4`→`中等`，`>0.1`→`较弱`，`≤0.1`→`极弱` |
| `{权重值}` | `CrowdTypeAttractionWeightsDto` | 该人群类型对目标区域类型的原始吸引力权重（0~1） |

### 9.4 出口来源优先级

`DecisionAgentPoint.BuildAvailableExits()` 按以下优先级收集候选出口：

1. **手动配置** — `availableExits[]` 数组（Inspector 中手动填写的出口选项），直接使用配置的 `exit_id`、`target_zone_id`、`nlDescription`
2. **拓扑自动生成** — 当 `autoBuildAvailableExitsFromTopology = true` 时，遍历 `TopologySceneConfig` 中所有 zone，将每个 zone 作为候选出口（`exit_id = target_zone_id = zone_id`），`nl_description` 置为占位文本
3. **地图数据富化** — `EnrichExitOptionsFromMapConfig()` 调用 `LocalCrowdDecisionEngine.EnrichExitOptionsWithMapScores()`，为每个出口动态计算：
   - `algorithm_score`：基于目标区域类型吸引力（×0.7）和容量（×0.3）的加权分
   - `nl_description`：覆盖为基于地图数据的自然语言描述

### 9.5 完整数据流

```
TopologySceneConfig (场景拓扑)
  ├─ TopologyZonePoint[]    → zone_id, zone_name, zone_type, capacity, bounds
  └─ TopologyExitPoint[]    → exit_id, source_zone_id, target_zone_id, pass_capacity

        ↓ BuildLookupMaps()

  zoneCapacityById, zoneTypeById, topologyExitById
        ↓
  EnrichExitOptionsWithMapScores()
        ↓
  每个出口:
    algorithm_score = attractionScore × 0.7 + capacityScore × 0.3
    nl_description  = "通往{exit_id}({zone_type中文}). {zone_type中文}对该类人群吸引力{强度}(权重{X})."

DecisionAgentPoint (agent 状态)
  ├─ crowdType          → ResolveCrowdTypeDisplayName → 角色名
  ├─ currentZoneId      → TryGetZoneById → zone_name → 区域名
  ├─ stayDurationMs     → 格式化 → 停留时间
  ├─ patienceRatio      → ResolvePatienceRatioLabel → 耐心标签
  └─ algorithmRecommendation → 反查 zone_type → 偏好区域类型

        ↓ BuildDilemmaSummary()

  dilemma_summary = "{角色名}已在{区域名}停留{时间}(耐心消耗{标签}), 偏好{区域类型}, 当前面临出口选择困境。"
```

### 9.6 LLM 接收的完整上下文

LLM 收到每个 agent 的请求包含两个自然语言信息源：

| 字段 | 作用 | 示例 |
|------|------|------|
| `dilemma_summary` | 一句话概括 agent 当前处境 | `观光游客已在主大厅停留16.2秒(耐心消耗较高，比较急迫(81%)), 偏好展览区, 当前面临出口选择困境。` |
| `available_exits[].nl_description` | 每个出口的静态地图属性描述 | `通往exit_exhibit_a(展览区). 展览区对该类人群吸引力很强(权重0.9).` |

LLM 结合这两个信息源 + `stay_duration_ms`、`patience_ratio`、`algorithm_score` 等数值字段，综合做出出口选择决策。
