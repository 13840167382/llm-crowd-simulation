# 轨迹叠加图生成器

这个本地小工具用于把轨迹文件中的行人轨迹叠加到底图图片上，生成类似航拍图上的轨迹叠加效果。默认会按空间重叠程度着色：轨迹越稀疏越绿，越密集越红。

## 启动

双击：

```text
启动轨迹叠加图生成器.bat
```

也可以运行：

```powershell
python trajectory_overlay_renderer.py
```

## 轨迹文件格式

支持两种输入。

### 轨迹表格式

支持 `.txt` / `.tsv` / `.csv`，需要包含表头，并至少有：

```text
x_world    y_world
```

推荐包含这些列，程序会自动使用：

```text
time_ms    agent_id    x_world    y_world    decision_mode
```

程序会按 `agent_id` 分组，再按 `time_ms` 排序，把同一个行人的点连成轨迹线。

### SDD 标注格式

也支持 Stanford Drone Dataset 的 `annotations.txt` 格式，不需要表头：

```text
track_id xmin ymin xmax ymax frame lost occluded generated "Pedestrian"
```

程序会自动只读取 `Pedestrian / Ped / Person`，并使用检测框中心点作为轨迹坐标：

```text
x = (xmin + xmax) / 2
y = (ymin + ymax) / 2
```

如果用 SDD 标注格式配原始图片，坐标范围通常可以设为图片像素范围，例如 `X: 0 到 图片宽度`，`Y: 0 到 图片高度`，并取消勾选“Y 轴向上为正”。

当前程序会自动识别 SDD 标注格式。选择底图后，会自动把坐标范围填成图片像素范围：

```text
X 最小 = 0
X 最大 = 图片宽度
Y 最小 = 0
Y 最大 = 图片高度
```

同时会自动取消“Y 轴向上为正”，因为 SDD 像素坐标是从图片左上角开始、Y 轴向下。

预览或导出前也会再次校正 SDD 坐标范围，避免界面里残留旧的 world 坐标范围导致轨迹和底图错位。

## 使用方法

1. 选择轨迹文件。
2. 选择底图图片。
3. 默认使用轨迹坐标的最小值和最大值作为世界坐标范围。
4. 如果底图有固定坐标边界，可以手动填写 `X 最小 / X 最大 / Y 最小 / Y 最大`。
5. 调整轨迹线宽、轨迹点大小、透明度、底图淡化、判红半径、红色线数和颜色方式。
6. 点击“预览叠加图”查看效果，点击“导出图片”保存。

默认颜色方式是“按叠加程度”：程序会统计每条轨迹附近一定范围内有多少条不同轨迹，再用绿色到红色表示附近轨迹数量。

- 判红半径：统计“附近轨迹”的像素范围，半径越大，离得更远的线也会互相影响。默认是 `12px`，太小会让相邻线出现明显红绿跳变。
- 红色线数：附近轨迹数量达到这个值时显示为红色；`1` 条到这个值之间会从绿色连续过渡到红色。默认是 `30` 条，最高可调到 `300` 条。

默认“底图淡化”为 `0`，不会给原图蒙白。如果希望轨迹更突出，可以少量调高这个值。

也可以切换为“按时间渐变”：较早的 `time_ms` 显示为绿色，较晚的 `time_ms` 显示为红色。如果没有有效时间，会按文件行顺序渐变。

## 实时预览

默认开启“自动预览”。程序会缓存轨迹投影和附近线数：

- 调整红色线数、透明度、底图淡化、颜色方式时，通常只重新上色，预览会更快。
- 调整判红半径、坐标范围、Y 轴方向、线宽或点大小时，需要重新计算附近线数。
- 默认开启“高保真”预览：先按原图尺寸渲染，再缩放到预览窗口，轨迹密集带形状更接近最终导出图。
- 如果预览太慢，可以取消“高保真”，程序会按当前预览窗口大小快速生成。导出图片始终使用当前参数生成原尺寸结果。

## 性能建议

“按叠加程度”模式已经使用空间索引加速。数据量特别大时，如果仍然觉得慢，可以：

1. 关闭“画轨迹点”，只画轨迹线。
2. 适当减小“判红半径”。
3. 使用更小分辨率的底图预览，确认参数后再导出高清底图。

如果轨迹上下颠倒，取消勾选“Y 轴向上为正”再生成。
