# 决策接口收口说明

本文档记录 `POST /api/v1/experiments/{experiment_id}/decisions` 当前已经落地的运行语义、真实模型适配边界和降级策略。

## 当前行为

- 接口字段仍保持和 PDF 一致：
  - 请求体包含 `batch_id`、`simulation_time_ms`、`agents`
  - 响应体包含 `processed_at_ms`、`processing_duration_ms`、`total_count`、`success_count`、`fallback_count`、`decisions`
- `success_count` 表示本批次由 LLM 成功给出结果的人数
- `fallback_count` 表示因 LLM 失败、超时或不可用而改走算法兜底的人数
- 如果实验配置 `fallback_to_algorithm=false`，则 LLM 失败时返回：
  - `chosen_exit_id = null`
  - `decision_source = "none"`
- 按 PDF `5.1` 的降级策略，`3001 / 3002 / 3003` 不作为本接口常规 HTTP 主路径返回：
  - 单人 LLM 调用失败或超时，吸收到该人物的 `fallback/none` 结果
  - 单人 LLM 返回格式无法解析，吸收到该人物的 `fallback/none` 结果
  - 整批超过硬超时，已完成人物正常返回，未处理人物标记为 `fallback/none`
- `3004` 仍作为接口级错误返回，典型场景是决策引擎整体不可用且当前实验不允许 fallback
- Redis 开启时，同一实验同时只允许存在 1 个未完成的决策请求
- 同一个 `batch_id` 仍然保持幂等回放；最终事实来源是数据库 `decision_batches(experiment_id, batch_id)` 唯一约束和响应快照，Redis 锁只负责减少并发处理中重复执行

## 当前的 LLM 适配层

当前默认使用 OpenAI 兼容真实模型决策引擎。测试、离线联调或纯后端压测可以临时改为 `heuristic`，主要作用是：

- 保持接口输出符合 `llm / fallback / none` 这套语义
- 让统计聚合、完成摘要、Redis 锁、RQ 后台任务链路继续正常工作

真实模型调用集中在：

- [llm_engine.py](<app/application/decisions/llm_engine.py>)

引擎选择与统一接口在：

- [engine.py](<app/application/decisions/engine.py>)

## 新增配置项

- `APP_DECISION_ENGINE_MODE`
  - 默认值：`openai_compatible`
  - 含义：当前决策引擎模式；支持 `openai_compatible` / `openai` / `llm` 和 `heuristic` / `mock` / `local`
- `APP_DECISION_PROVIDER_BASE_URL`
  - 默认值：`https://api.openai.com/v1`
  - 含义：OpenAI Chat Completions 兼容服务地址
- `APP_DECISION_PROVIDER_API_KEY`
  - 默认值：空
  - 含义：真实模型服务密钥；为空时真实模型模式不可用
- `APP_DECISION_PROVIDER_MODEL`
  - 默认值：空
  - 含义：模型名覆盖；为空时使用实验 `llm_config.model`
- `APP_DECISION_PROVIDER_TEMPERATURE`
  - 默认值：`0`
  - 含义：真实模型调用温度
- `APP_DECISION_PROMPT_VERSION`
  - 默认值：`v1`
  - 含义：Prompt 构造版本
- `APP_DECISION_BATCH_HARD_TIMEOUT_SECONDS`
  - 默认值：`8`
  - 含义：整批决策的硬超时时间
- `APP_DECISION_BATCH_MAX_CONCURRENCY`
  - 默认值：`4`
  - 含义：单批 agent 决策最大并发数；设为 `1` 时退回串行处理
- `APP_DECISION_BATCH_LOCK_TTL_SECONDS`
  - 默认值：`30`
  - 含义：同一实验同一 `batch_id` 的处理锁 TTL
- `APP_DECISION_EXPERIMENT_LOCK_TTL_SECONDS`
  - 默认值：`30`
  - 含义：实验级决策并发锁 TTL
